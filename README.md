# BAKE 180º Foods & Desserts — prévia do site

Prévia navegável do novo site institucional da BAKE 180º.

**Ver online:** ative o GitHub Pages em *Settings → Pages → Branch: main /(root)*
e o site fica em `https://obuenoh.github.io/Bake180-preview/`

## O que dá para fazer

- Navegar pelas **três páginas**: início, catálogo e perguntas frequentes
- Ver os **47 produtos** — brownies, cookies, tortas e cremes — com filtro por
  categoria, versão vegana e itens personalizáveis
- Abrir qualquer produto e ver descrição, formatos e conservação
- Montar uma **cotação**: junte os itens que interessam e o site monta a
  mensagem de orçamento pronta para o WhatsApp

## Como o site foi pensado

A BAKE 180º atende empresas, não consumidor final. Então o site **não vende**:
não existe preço, carrinho nem finalização de compra em lugar nenhum. Cada
página termina num caminho de contato — WhatsApp ou formulário.

As fotos são as da própria BAKE 180º. Nada aqui é banco de imagem.

É um arquivo único, sem dependência externa: abra `index.html` em qualquer
navegador e funciona, inclusive offline.
